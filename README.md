# Notes3
An minimalist Note Taking App that uses Markdown for rendering notes in MERN Stack.

## Write in markdown -> Save in HTML
<img src="https://github.com/user-attachments/assets/fb5cad88-e45a-40c5-b064-2fd444de063d" style="width:100vw;" ></img>


The App is written in MERN stacks using MongoDB Atlas as serverless database URI.

### Frontend Dependencies

- ![axios](https://img.shields.io/badge/-axios-5A29E4?logo=axios&logoColor=white) : For API Calls
- ![gsap](https://img.shields.io/badge/-gsap-88CE02?logo=greensock&logoColor=white) : Entry animations
- ![mui](https://img.shields.io/badge/-mui-007FFF?logo=mui&logoColor=white) + ![react-icons](https://img.shields.io/badge/-react--icons-61DAFB?logo=react&logoColor=white) : For icons
- ![react-markdown](https://img.shields.io/badge/-react--markdown-000000?logo=markdown&logoColor=white) : To render HTML from markdown
- ![react-modal](https://img.shields.io/badge/-react--modal-61DAFB?logo=react&logoColor=white) : For modals
- ![react-router](https://img.shields.io/badge/-react--router-CA4245?logo=reactrouter&logoColor=white) + ![react-router-dom](https://img.shields.io/badge/-react--router--dom-CA4245?logo=reactrouter&logoColor=white) : For routing
- ![rehype-raw](https://img.shields.io/badge/-rehype--raw-8BC34A?logo=remark&logoColor=white) (DEPRECATED/UNUSED) + ![remark-gfm](https://img.shields.io/badge/-remark--gfm-8BC34A?logo=remark&logoColor=white) (DEPRECATED/UNUSED) : To give markdown elements prebuilt CSS
- ![tailwindcss](https://img.shields.io/badge/-tailwindcss-06B6D4?logo=tailwindcss&logoColor=white) : For efficient CSS addition to HTML tags

### Backend Dependencies
